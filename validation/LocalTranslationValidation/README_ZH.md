# 本地保存与翻译技术验证

这不是 Oh My House 正式 App，也不是正式页面的雏形。

它只验证两件事：

1. 使用 Core Data 保存的测试内容，关闭并重新打开 App 后仍然存在；
2. Apple Translation 可以在中文和英文之间翻译，并在翻译暂不可用时保留原文。

测试程序不会使用 iCloud、家庭真实资料、相册或正式账号。

## 手动验证方法

1. 在 Xcode 中打开 `LocalTranslationValidation.xcodeproj`；
2. 选择一台 iPhone 模拟器或 `My Mac`；
3. 运行程序；
4. 输入虚构内容，例如“买牛奶”；
5. 选择翻译方向并点击“开始翻译”；
6. 点击“保存这条测试内容”；
7. 完全关闭程序，再次打开；
8. 确认已保存内容仍然存在。

首次翻译时，系统可能要求下载 Apple 的中文或英文语言包，这是预期行为。
