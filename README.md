# Oh My House

Oh My House 是一个面向 2–4 人小家庭的轻量 Household Companion。

它希望用一个简单、温暖、低摩擦的 App，协调共同生活中真正需要共享的信息和日常事务。

## 当前状态

项目仍处于 **Product Design / Architecture Planning** 阶段，尚未开始写代码，也尚未选择技术实现。

当前确认的核心领域：

- Meals
- Chores
- Shopping
- Home Wishlist
- Home Inventory
- Home Maintenance
- Household Events
- Today / Calendar
- 中英文 UI 与共享内容自动翻译

``` text

```

或复杂的 productivity suite。
